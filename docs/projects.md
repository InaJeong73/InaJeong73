# Project guide

프로젝트별 코드 접근 경로와 공개 범위입니다. 확인 기준: 2026-09-20.

| 프로젝트 | 코드·자료 | 공개 범위 |
| --- | --- | --- |
| PORI | [개인 개발본](https://github.com/InaJeong73/pori-backend) · [팀 원본](https://github.com/Aingthon/Propofol_BE) | 공개. 백엔드 평가 로직은 현재 모의 평가 구현이며 실제 AI 모델 연동과 구분합니다. |
| Dear.K | [개인 개발본](https://github.com/InaJeong73/deark-backend) · [팀 원본](https://github.com/kusitms-dear-k/DEAR.K_BE) | 공개. 조회·주문 API와 배포 구성을 확인할 수 있습니다. 포트폴리오의 후속 Pinecone 통합검색 코드는 현재 공개 브랜치에서 확인되지 않습니다. |
| AiSAC | [경험 요약](aisac.md) | 팀 소스 저장소는 비공개입니다. 공개 코드를 제공하는 링크로 안내하지 않습니다. |
| 칙폭이 | [RAG 실험 요약](rail-rag.md) | 현재 이 GitHub 계정에서 공개 소스 경로를 제공하지 않습니다. |
| AjouFinder | [소스](https://github.com/InaJeong73/AjouFinder) | 공개 개인 프로젝트. DB 수업의 별도 팀 저장소와 구분합니다. |
| 교내 분실물 통합 플랫폼 | [팀 소스](https://github.com/Database-team8/DB-TEAM6-BE) | 공개 팀 프로젝트. |
| Ondue | [팀 소스](https://github.com/TheAverageAgeHasGottenYounger/back) | 공개 팀 프로젝트. 백엔드 개발 참여 경험이며 전체 기능의 단독 기여를 의미하지 않습니다. |
| TtoGal | [개인 fork](https://github.com/InaJeong73/Ttogal) | 공개. 현재 체크아웃의 회원·이메일 인증 구현 범위를 README에 안내합니다. |
| RoadMaster | [소스](https://github.com/InaJeong73/RoadMaster) | 공개 Java 수업 프로젝트. |

팀 프로젝트의 원본 작성자와 커밋 이력은 각 저장소에 보존합니다. 개인 저장소의 후속 변경은 팀의 현재 운영 버전을 의미하지 않습니다.
