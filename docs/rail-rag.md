# 칙폭이 — 기차 이용규정 RAG 챗봇

SSAFY AI 관통 프로젝트 · 2026.09 · 백엔드·RAG 파이프라인·청킹 실험 설계 담당

철도 이용약관 PDF 3종을 검색해 질문에 답하는 챗봇입니다. FastAPI, LangGraph, LangChain, ChromaDB를 사용했습니다. 문서 업로드 → 청킹 → 임베딩 → 검색 → 답변 흐름을 구현하고 출처 파일명을 표시하도록 했습니다.

## 비교한 질문

고정 크기 분할보다 조·항과 표의 구조를 보존하는 분할이 항상 유리할까요?

- 고정 크기, 조·항+표 인라인, 조·항+표 분리의 3가지 전략을 비교했습니다.
- 큰 청크에 유리한 동일 k 비교 대신 약 2,500자의 검색 문자 예산을 적용했습니다.
- 직접 구성한 12문항, 2회 반복, Ragas 4지표와 답변 거절 0점 처리 기준을 사용했습니다.
- 이 조건에서는 고정 크기 분할이 종합 점수 **0.7264**로 가장 높았습니다. 대형 표의 임베딩과 회수 다양성, 답변 거절의 영향을 분석했습니다.

위 결과는 소규모 실험의 기록이며 일반적인 RAG 성능을 의미하지 않습니다. 현재 이 계정에 공개된 실험 소스·평가 산출물 링크는 없습니다. 하이브리드 검색과 리랭커는 후속 개선 후보입니다.
