# AiSAC — AI 광고 창작 지원

KOBACO × KUSITMS 산학협력 프로젝트 · 2025.02–03 · 팀 8명 / 백엔드 2명

광고의 주제·톤·키워드를 입력하면 방향성, 시나리오·대사와 장면별 이미지를 생성하고, 결과물에 수정 요청을 보낼 수 있는 서비스입니다. 팀 소스는 비공개이며 이 문서는 담당 경험의 요약입니다.

## 담당 역할

백엔드 리더로 아키텍처·ERD 설계, 이미지 생성 모델 조사, 광고 이미지·대사 생성 기능, NCP 배포 파이프라인 구축을 담당했습니다. Clova Studio와 DALL·E를 Spring Boot에 연동했습니다.

## 외부 API 처리 개선

독립적인 이미지 생성 단계를 병렬로 처리하고 의존 단계의 순서를 유지했습니다. 동시 호출 수와 배치를 제한해 외부 API 요청 한도에 대응했으며, 블로킹 S3 업로드는 전용 실행기로 분리했습니다.

프로젝트 당시 광고 이미지 생성 API 응답시간은 **12.8초 → 4.6초**로 개선했습니다. 이 수치는 당시의 프로젝트 기록이며, 공개 저장소에 재현 가능한 벤치마크가 제공되는 것은 아닙니다. 전체 서비스 응답시간이나 운영 부하 테스트 결과로 확대하지 않습니다.
